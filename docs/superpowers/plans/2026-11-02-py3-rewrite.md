# AShareListedCompanyList Python 3 重写实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 Python 3 + requests 重写沪深 A 股数据采集工具：公司列表（A+ 字段全量快照）与市场统计（按日长表），输出本地 CSV/Excel，无数据库。

**Architecture:** 五模块单包 `src/ashare/`：httpclient（统一 HTTP：UA/Referer/限速/重试/jsonp 剥壳）、clean（纯函数数据清洗）、sse/szse（两所抓取与解析，产出统一中文键字典）、storage（CSV/xlsx 落盘与幂等追加）、main（CLI 编排）。解析与清洗全部为纯函数或注入 fake client 的可测函数；真实接口的未知细节（分页参数、STOCK_TYPE、详情接口路径、统计 xlsx 列布局）在各任务第一步用浏览器/ curl 实测后固化进 fixture 与常量。

**Tech Stack:** Python 3.10+，requests，pandas，openpyxl；测试 pytest（requests 用 monkeypatch 假对象，不发真实网络）。

**Spec:** `docs/superpowers/specs/2026-11-02-py3-rewrite-design.md`

## Global Constraints

- Windows 11，Python 3.10+；运行依赖仅 requests/pandas/openpyxl
- 所有 CSV 用 `utf-8-sig` 编码（Excel 中文不乱码）
- 所有请求：浏览器 UA + 对应站点 Referer；请求间隔 ≥0.3s；失败重试 3 次
- 深交所请求需额外头 `x-requested-with: XMLHttpRequest`
- 公司快照口径：当前在市（含 ST/暂停上市），不含退市；深市只抓 A 股（tab1）
- stats 无数据（非交易日/接口空）：跳过写行、打印提示、退出码 0，不覆盖已有行
- 公司 dict 与统计 dict 的键 = 最终 CSV 中文列名（见 Task 6 的 `COMPANY_COLUMNS`/`STATS_COLUMNS`，两所解析器共用）
- commit 消息：conventional 前缀 + 中文描述，结尾加 `Co-Authored-By: Claude Code <noreply@anthropic.com>`
- 偏离设计之处：上交所统计的"HTML 页面解析备选"不实现（xlsx 接口失败时按"无数据"跳过），已在交付时向用户说明

## Review Focus

1. **jsonp 回调名随机**（`jsonpCallback98088922(...)` 每次不同）→ `strip_jsonp` 必须正则匹配任意回调名，不得假设固定前缀长度（老项目 bug）→ Task 1 测试
2. **深交所简称含 HTML**（`<a href='...'><u>平安银行</u></a>`）→ CSV 中必须是纯文本 → Task 2/3 测试
3. **日期多格式**（沪 `20210525`、深 `1991-04-03`、可能带时间后缀）→ 统一 `YYYY-MM-DD`，无法解析给 `''` → Task 2 测试
4. **千分位数字与 `'-'` 占位**（`363,558.55`、`B_STOCK_CODE='-'`）→ 数值化与空值化 → Task 2 测试
5. **深交所统计响应混入指数行**（深证成指/深证综指/创业板指与"上市公司数"等同级）→ 按指标名精确匹配，指数行必须被排除 → Task 7 测试

        text = '{}'; encoding = 'utf-8'

    assert seen['headers']['Referer'] == "http://www.szse.cn/"
    assert seen['headers']['x-requested-with'] == "XMLHttpRequest"

def test_retry_exhausted_raises(monkeypatch):
    import requests as real
    def fake_get(url, **kw): raise real.exceptions.Timeout("t")
    monkeypatch.setattr("src.ashare.httpclient.requests.get", fake_get)
    with pytest.raises(RuntimeError):
        HttpClient(referer="http://x/", retries=3, min_interval=0).get_json("http://x/")

def test_retry_then_success(monkeypatch):

    n = {"i": 0}
    class FakeResp:
        text = '{"ok": true}'
    def fake_get(url, **kw):
        n["i"] += 1
        if n["i"] < 3: raise Timeout("t")
        return FakeResp()
    monkeypatch.setattr("src.ashare.httpclient.requests.get", fake_get)
    c = HttpClient(referer="http://x/", retries=3, min_interval=0)
