# AShareListedCompanyList

沪深 A 股上市公司列表与市场统计抓取工具（Python 3 版）。

数据直接来自上交所、深交所官网公开接口，落地为本地 CSV/Excel 文件（`utf-8-sig` 编码，Excel 双击打开中文不乱码）。不依赖数据库。

> 原 2016-2018 年的 Python 2 + MySQL 实现已因两所官网改版不可运行，本次为完全重写；旧代码已删除，需要时可从 git 历史找回。

## 安装

- Python 3.10+（开发验证环境为 3.13）
- 依赖：requests / pandas / openpyxl / xlrd（测试另需 pytest）

```bash
pip install -r requirements.txt
```

运行测试（40 个用例，全部离线，不访问网络）：

```bash
python -m pytest tests/ -v
```

## 使用

```bash
python -m src.ashare.main companies                       # 全量公司列表（覆盖快照）
python -m src.ashare.main stats --date 2026-10-30         # 指定日期市场统计（默认今天）
python -m src.ashare.main all                             # companies + stats
```

通用选项：

| 选项 | 默认 | 说明 |
|---|---|---|
| `--date YYYY-MM-DD` | 今天 | 统计日期，仅 `stats` / `all` 使用 |
| `--data-dir PATH` | `./data` | 输出目录（不存在会自动创建） |

退出码：`0` 正常（含"无数据跳过"），`1` 失败（异常已捕获并打印）。

### companies —— 公司列表全量快照

- 深交所 A 股列表（主板 + 创业板）+ 上交所 A 股列表（主板 + 科创板）
- 上交所每家公司再请求 公司概况 / 股本结构 详情接口，补齐 注册地址、公司网址、A 股总股本、A 股流通股本；有 B 股代码的公司补 B 股上市日期
- 两市合计约 5200 家；因官网限速（请求间隔 0.3s），全量运行约 25-30 分钟
- 快照口径：当前在市公司（含 ST/\*ST/暂停上市），**不含退市公司**
- 覆盖式写入（同名文件每次整体重写）

### stats —— 市场统计（按日追加）

- 每个交易日写入 4 行：沪市 整体 / 主板 / 科创板 + 深市 整体
- 幂等追加：按 日期+交易所+板块 去重，同日重跑覆盖旧行，不影响其它日期
- 目标日期无数据（非交易日/接口为空）：打印提示、退出码 0、不写任何行，已有数据绝不被空数据覆盖

## 输出文件

```
data/
  companies_latest.csv             # 最新全量快照（固定名，覆盖写）
  A股上市公司列表_YYYY-MM-DD.xlsx   # 同快照的 Excel 版，三 sheet：全部 / 上海 / 深圳
  market_stats.csv                 # 市场统计长表（追加式，幂等）
```

`data/` 已在 `.gitignore` 中，抓取结果不入库。

## 字段说明

### 公司列表（19 列）

| 列 | 说明 |
|---|---|
| 交易所 | SSE（沪）/ SZSE（深） |
| 公司代码 / A股代码 | 两所统一 6 位代码 |
| A股简称 | 深市原始值含 HTML 链接，已清洗 |
| 公司全称 / 英文全称 | 仅沪市有（列表接口直接返回）；深市留空 |
| 板块 | 沪：主板/科创板；深：主板/创业板 |
| A股上市日期 | 统一 YYYY-MM-DD |
| A股总股本(股) / A股流通股本(股) | **单位为股**。沪市来自详情接口；深市接口为亿股，已 ×10^8 换算为股 |
| B股代码 / B股上市日期 | **仅沪市部分公司**（有 B 股的才有值）；深市留空 |
| 省份 / 注册地址 / 公司网址 | 仅沪市有；深市接口不提供，留空 |
| 所属行业 | **沪深口径不同**：沪市为证监会行业描述，深市为门类简称（如 `J 金融业`），列名统一但不可直接混用 |
| 上市状态 | 沪市按状态码映射（上市/ST 等）；深市固定"上市" |
| 退市日期 | 在市快照下一般为空 |
| 抓取日期 | 运行日 |

注：沪市详情补齐字段以官方接口实际返回为准。少数公司源数据本身缺失（如未披露公司网址、股本结构接口无记录，2026-11 实测约 14% 沪市公司无股本记录、7% 无网址），对应字段留空——这是源数据缺失，不是抓取失败。

### 市场统计（13 列，长表）

一行 = 日期 × 交易所 × 板块。

| 列 | 说明 |
|---|---|
| 日期 / 交易所 / 板块 | 幂等键。板块：沪 整体/主板/科创板，深 整体 |
| 上市公司数 / 上市证券数 | 家数（沪市"上市证券数"为上市股票数口径） |
| 总股本 / 流通股本 | **单位亿股** |
| 总市值 / 流通市值 / 成交金额 | **单位亿元** |
| 平均市盈率 | 倍 |
| 平均股价(元) / 换手率(%) | **仅深市整体行有值**，沪市三行留空（沪所统计表不提供） |

## 稳定性与反爬

- 所有请求带 Chrome UA 与对应站点 Referer（深交所另带 `x-requested-with: XMLHttpRequest`）
- 请求间隔 ≥ 0.3s；超时/连接失败/HTTP 4xx 5xx 自动重试 3 次，耗尽抛错
- 沪市详情接口单家失败 → 该公司补齐字段留空继续；连续 5 家失败 → 判定接口不可用，整体降级为列表字段并打印提示

## 非目标（明确不做）

- 年报/半年报等定期报告的财务数据（数字在 PDF 内，请另行处理）
- PDF 下载与解析
- 第三方数据源（巨潮资讯等）
- B 股股本明细（两所接口均不提供）
- 城市字段（两所接口均无；老项目的"城市"本就是省份复制值）
- 定时调度（手动运行）

## 项目结构

```
src/ashare/
  httpclient.py   # requests 封装：UA/Referer/限速/重试/jsonp 剥壳
  sse.py          # 上交所：列表分页、详情补齐、市场统计
  szse.py         # 深交所：列表分页、市场统计
  clean.py        # 数据清洗纯函数（HTML/日期/千分位/占位符）
  storage.py      # CSV(utf-8-sig)/xlsx 落盘、幂等追加
  main.py         # CLI 入口
tests/            # pytest 离线用例（fixtures 为真实接口响应样本）
```
